# My To-Do List

A simple, responsive to-do list application built with HTML, CSS, and vanilla JavaScript.

## Features

- Add a task using the form
- Delete tasks individually
- Responsive layout for desktop and mobile screens
- Accessible form labels and delete-button descriptions
- Automatic focus after adding a task

## Project Structure

- `Index.html` - Application markup
- `styles.css` - Page layout and visual styling
- `script.js` - Task creation and deletion behavior

## Getting Started

No build tools or dependencies are required.

1. Open `Index.html` in a web browser.
2. Enter a task in the text field.
3. Select **Add Task**.
4. Select **Delete** beside a task to remove it.

Alternatively, serve the project locally:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000/Index.html` in your browser.
